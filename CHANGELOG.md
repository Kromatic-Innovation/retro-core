# Changelog

All notable changes to this package. This project follows
[Semantic Versioning](https://semver.org/); while the major version is `0`, a
minor bump may break the API and a patch bump never does.

## 0.1.1

No change to runtime behaviour. Documentation and packaging only.

- README gains a north star, non-goals, and a repository map.
- The published file's header comments no longer carry pre-release internal
  references. The executable code is identical to 0.1.0.
- First release published through the tag-triggered, OIDC trusted-publishing
  workflow.

## 0.1.0

- Initial release: `runRetro` and `printOnlyRouter`.
